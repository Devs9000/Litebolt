# About

LiteBolt is a collection of optimized Windows builds designed to provide better performance, lower resource usage, and a cleaner experience while maintaining compatibility with the Microsoft Windows ecosystem.

Every LiteBolt release starts from an official Microsoft Windows image and is carefully optimized to reduce unnecessary components while preserving compatibility, Windows Update support, drivers, and modern applications.
